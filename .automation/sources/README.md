# Saved paper sources

`index.json` maps original download paths and source records to files in `files/`. Files use their SHA-256 as the filename; duplicate downloads share one file. PDFs, HTML, supplements, extracted text, registry metadata and rendered pages are retained.

Search the index by paper title, URL or original filename. The audit reports now point to these permanent paths. Extracted text and screenshots are reading aids; their presence does not establish a completed audit or an accessible published version.
