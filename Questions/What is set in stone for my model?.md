## Agent
- each agent has constraints (material)
	- time availability
	- location
	- travel factor
	- price factor
- each agent has internal state for making decisions (immaterial)
	- static (genetics)
	- slow changing (opinions)
	- instant changing (knowledge) 
- decisions are only made based on internal state
- relationship is agent state

## Event
- events can have constraints
	- time availability
	- location
	- price
- agents can attend event
- attended events influence agent state
