## How to import:
- Title of the file should be a santitized version of the original title
- **read status**:  
	- **None**: not yet read - default 
	- **Scan**: extracted some information but not complet read
	- **Read**: completly read and internalized
- **category**: coarse subject areas, e.g. design science, sociology, social matching; multiple values allowed
- **tags**: specific content, e.g. homophily, specificity, mixed_effects; no note or publication types
- **doi**: clickable DOI URL, e.g. https://doi.org/10.1086/225469
- **pdf**: link to an existing local PDF in 00_Resources/Attachments/Papers; leave empty if unavailable. No online PDF URLs.
